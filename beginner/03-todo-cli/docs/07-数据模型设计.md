## 设计思路

冻结数据类表达存储快照；创建前和更新前通过 validate_fields 统一验证，任务 ID 必须为正整数。 本项目对任务创建允许相同标题，使用 ID 区分。持久化时间以 UTC 记录，截止日期按 YYYY-MM-DD 验证。

## 核心代码

下面摘自当前实际实现 [models.py](../src/taskflow/models.py)。

```python
"""任务数据与输入约束。"""

from dataclasses import dataclass
from datetime import date, datetime

from .exceptions import ValidationError

PRIORITIES = ("low", "normal", "high")
STATUSES = ("pending", "completed")


def validate_fields(fields: dict[str, object]) -> dict[str, object]:
    """校验并规范字段，拒绝未知列。"""
    allowed = {"title", "description", "priority", "status", "due_date"}
    if set(fields) - allowed:
        raise ValidationError("存在未知字段")
    result = dict(fields)
    if "title" in result:
        title = result["title"]
        if not isinstance(title, str) or not 1 <= len(title.strip()) <= 200:
            raise ValidationError("标题去空白后必须为 1 到 200 个字符")
        result["title"] = title.strip()
    if "description" in result:
        if not isinstance(result["description"], str) or len(result["description"]) > 10000:
            raise ValidationError("描述必须为不超过 10000 字的文本")
    if "priority" in result and result["priority"] not in PRIORITIES:
        raise ValidationError("优先级应为 low、normal 或 high")
    if "status" in result and result["status"] not in STATUSES:
        raise ValidationError("状态应为 pending 或 completed")
    if "due_date" in result and result["due_date"] is not None:
        try:
            value = result["due_date"]
            if not isinstance(value, str) or date.fromisoformat(value).isoformat() != value:
                raise ValueError
        except (ValueError, TypeError):
            raise ValidationError("日期应为 YYYY-MM-DD") from None
    return result


def validate_id(task_id: int) -> None:
    """任务 ID 必须是正整数。"""
    if type(task_id) is not int or task_id < 1:
        raise ValidationError("任务 ID 必须为正整数")


@dataclass(frozen=True)
class Task:
    """持久化任务快照，时间为 UTC ISO 格式。"""

    id: int
    title: str
    description: str
    priority: str
    status: str
    due_date: str | None
    created_at: str
    updated_at: str

    def __post_init__(self) -> None:
        validate_id(self.id)
        validate_fields(
            {
                "title": self.title,
                "description": self.description,
                "priority": self.priority,
                "status": self.status,
                "due_date": self.due_date,
            }
        )
        for value in (self.created_at, self.updated_at):
            try:
                timestamp = datetime.fromisoformat(value)
                if timestamp.tzinfo is None:
                    raise ValueError
            except ValueError:
                raise ValidationError("时间必须包含时区") from None
```

## 代码解释

先限制字段集合，再校验标题、描述、枚举和日期。Task 构造时验证 ID 与时间字段，保证返回对象满足基本不变量。

## 运行方法

在项目目录执行编辑安装：

```bash
python -m pip install -e .
python -m taskflow --db demo.db add "学习 Python" --priority high
python -m taskflow --db demo.db add "边界" --due-date 2030-01-01
```

首次演练从新数据库开始，已有数据库时按实际新增返回的 ID 替换示例中的 1。正常查询打印 JSON；不存在任务打印错误到 stderr 并返回 1。帮助命令不创建数据库。

## 常见问题

- 找不到 taskflow 时检查当前解释器是否完成编辑安装。
- 日期错误时用完整的 YYYY-MM-DD，空标题和大于 200 字的标题也会被拒绝。
- 数据不一致时检查 --db 与 TASKFLOW_DB，确认调用的是同一数据库。
- CSV 按文本导入；导出内容保留原文，不对标题自动改写。
