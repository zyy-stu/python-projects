## 核心代码

下面摘自当前实际实现 [database.py](../src/taskflow/database.py)。

```python
"""SQLite 连接、约束与事务。"""

import sqlite3
from collections.abc import Iterator
from contextlib import contextmanager
from pathlib import Path

SCHEMA = """
CREATE TABLE IF NOT EXISTS tasks (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title TEXT NOT NULL CHECK(length(trim(title)) BETWEEN 1 AND 200),
    description TEXT NOT NULL DEFAULT '' CHECK(length(description) <= 10000),
    priority TEXT NOT NULL CHECK(priority IN ('low','normal','high')),
    status TEXT NOT NULL CHECK(status IN ('pending','completed')),
    due_date TEXT,
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_tasks_status_priority ON tasks(status, priority);
CREATE INDEX IF NOT EXISTS idx_tasks_due_date ON tasks(due_date);
"""


class Database:
    """每次操作独立连接，成功提交，异常回滚，最后关闭。"""

    def __init__(self, path: Path) -> None:
        self.path = path
        path.parent.mkdir(parents=True, exist_ok=True)
        with self.connect() as connection:
            connection.executescript(SCHEMA)

    @contextmanager
    def connect(self) -> Iterator[sqlite3.Connection]:
        connection = sqlite3.connect(self.path, timeout=10)
        connection.row_factory = sqlite3.Row
        try:
            with connection:
                yield connection
        finally:
            connection.close()
```

## 代码解释

SCHEMA 中 SQL 定义持久化约束。connect 的 with connection 决定事务提交或回滚，finally 总会关闭连接。

## 运行方法

在项目目录执行编辑安装：

```bash
python -m pip install -e .
python -m taskflow --db demo.db add "学习 Python" --priority high
python -m taskflow --db demo.db list
```

首次演练从新数据库开始，已有数据库时按实际新增返回的 ID 替换示例中的 1。正常查询打印 JSON；不存在任务打印错误到 stderr 并返回 1。帮助命令不创建数据库。

安装开发依赖后运行相关测试和完整测试：

核对[实际测试文件](../tests/test_database.py)的断言。测试数据放在 tmp_path，CLI 测试通过 TASKFLOW_DB 指向临时文件。测试运行结果以关联提交的 CI 为准。

## 常见问题

- 找不到 taskflow 时检查当前解释器是否完成编辑安装。
- 日期错误时用完整的 YYYY-MM-DD，空标题和大于 200 字的标题也会被拒绝。
- 数据不一致时检查 --db 与 TASKFLOW_DB，确认调用的是同一数据库。
- CSV 按文本导入；导出内容保留原文，不对标题自动改写。
