# Repository 数据访问层

## 本章目标与前置知识

每个写操作在单个事务内完成，返回刚写入的任务快照。 需要了解 Python 函数、模块和异常。

## 设计思路、核心代码与解释

从[repository.py](../src/taskflow/repository.py)中的 `TaskRepository` 开始阅读。每个写操作在单个事务内完成，返回刚写入的任务快照。
例如更新先验证字段白名单，再把值作为 SQL 参数绑定；列名只来自白名单。

## 运行和测试

在项目目录安装 `python -m pip install -e .`。按[使用演练](../examples/usage.md)执行相关命令，再运行 `python -m pytest`。检查过程中使用 `--db demo.db` 指定演练数据库。

## 常见问题与总结

导入错误时确认已经完成编辑安装；数据不符合预期时先确认环境变量或命令行覆盖后的数据库路径。每个写操作在单个事务内完成，返回刚写入的任务快照。
