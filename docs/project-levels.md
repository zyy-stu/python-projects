# 项目四级体系

| 等级 | 人群与前置知识 | 技术与目标 | 验收 | 顺序 |
| --- | --- | --- | --- | --- |
| Level 1 | 能使用变量、类型、条件、循环、函数与容器 | 文件、异常、简单 CLI | 能独立运行和处理非法输入 | Hello CLI → 计算器 → Todo → 文件管理 → 密码生成 → 学生管理 → 记账 |
| Level 2 | 掌握基础和模块 | OOP、SQLite、SQLAlchemy、日志、配置、pytest、REST API | 模块化、持久化和测试 | 任务系统 → 图书 → 库存 → 博客 → Web API |
| Level 3 | 能交付模块化项目 | 并发、异步、多进程、设计模式、插件、缓存、队列和优化 | 失败隔离、资源回收和可复现性能基线 | 插件 → 调度 → 缓存 → 爬虫 → 队列 → 分布式任务 |
| Level 4 | 有服务开发与测试经验 | 需求、架构、数据库、API、前后端、权限、Docker、部署和监控 | 干净环境交付完整闭环 | 个人管理 → 博客 → 知识平台 → AI 平台 |

TaskFlow 标注为 Level 1 到 Level 2 的过渡，放在初级目录供循序实践。
