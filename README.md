# Python 实战项目

Python Learning Roadmap 的综合实战仓库。面向已掌握基础语法的学习者，将需求、架构、存储、编码、测试、打包、文档和持续集成组合为可运行软件。

## 从这里开始

阅读[项目分级](docs/project-levels.md)、[学习路线](docs/project-learning-path.md)和[开发流程](docs/project-development-process.md)，再运行第一个完整项目 [TaskFlow CLI](beginner/03-todo-cli/README.md)。

## 验证

根目录安装 `requirements-dev.txt` 及 TaskFlow 和三个模板的编辑包，然后运行 `python -m pytest`、`python -m ruff check .` 和 `python -m ruff format --check .`。各项目 README 提供独立安装方式。
